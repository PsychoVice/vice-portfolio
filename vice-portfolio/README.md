# VICE — photography portfolio

Static portfolio website for GitHub Pages.

## Files
- `index.html` — page structure and Russian copy
- `styles.css` — responsive visual design
- `script.js` — mobile navigation
- `images/` — put your own photographs here

## Add your photos
Replace these image files with your own:
- `images/hero.jpg` — wide hero image
- `images/concert.jpg` — concert portfolio cover
- `images/portraits.jpg` — portrait / personal shoots cover

Keep the filenames exactly the same, or update the paths in `styles.css`.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**.
Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
